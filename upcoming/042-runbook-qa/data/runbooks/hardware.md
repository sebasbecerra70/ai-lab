# Hardware Operations

## Failed disk replacement
1. Confirm the failed drive slot and serial number from the server's management controller.
2. Verify the RAID array is degraded but not failed, and that no rebuild is in progress.
3. Get the customer's change approval if the server is customer-owned.
4. Hot-swap the drive using an anti-static strap, matching the exact replacement part number.
5. Confirm the rebuild started and record the old drive serial in the RMA log.
6. Place the failed drive in the secure destruction bin; never ship it back with data on it.

## Server RMA shipment
1. Open an RMA with the vendor portal and record the RMA number in the ticket.
2. Remove all drives and keep them on site for secure destruction.
3. Pack the server in the vendor-supplied packaging with the RMA label attached.
4. Schedule pickup through the shipping dock and log the tracking number.
