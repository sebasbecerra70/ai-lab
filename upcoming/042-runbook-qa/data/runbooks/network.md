# Network Operations

## Uplink down
1. Check the interface status and error counters on both ends of the link.
2. Confirm traffic failed over to the redundant uplink and check its utilization.
3. Inspect and clean the fiber connectors, then reseat the optics.
4. If the link stays down, swap the optic with a known-good spare.
5. Open a ticket with the carrier if the fault is outside the building.

## Cross-connect request
1. Verify the customer's letter of authorization and the target port in the meet-me room.
2. Assign a patch panel port in DCIM and print the cable label.
3. Run, label and test the cross-connect, then send the test results to the customer.
